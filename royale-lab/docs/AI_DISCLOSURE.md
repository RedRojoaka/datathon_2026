# AI-use disclosure

Draft disclosure for the team's appendix; update if actual usage changes.

An AI coding assistant helped inspect the supplied participant materials, implement the analysis pipeline and dashboard, document Tableau workflows, and draft presentation options. Financial calculations, forecasts, validation metrics and exported evidence are produced by reproducible local Python code from the supplied data, not generated by a language model. Team members should review the code and findings before submission.

The project includes a Gemini management-briefing page and evidence-explanation endpoint. Generation requires a locally configured API key and an explicit request. No real Gemini API calls were used during implementation or automated testing; tests use isolated mocked responses. When enabled, it explains supplied evidence, alternatives and limitations across forecast, machine, guest and budget topics. Genuine successful responses export to a small Tableau CSV with evidence IDs, scope, model and timestamp. It does not compute financial results, train the demand model, estimate causal lift or choose an optimal spending allocation.

If Gemini is enabled during the project/demo, record the model, date, evidence identifiers used and approximate usage here. Do not claim it was used if it remained disabled. The static hosted dashboard has no paid AI endpoint and no embedded API key.

Run `python3 package_submission.py` after generating real briefings to include the generated text and usage record in the packaged disclosure. The runtime allowance is a conservative local reservation, not an authoritative Google bill.
