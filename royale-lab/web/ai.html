Connect Gemini locally and add the briefing to Tableau

1. Create your key

Open Google AI Studio → API keys. Create a key in the project associated with your $10 Gemini credits.

Keep the key in your local setup. Confirm credit eligibility, disable automatic reload, and use a project spending cap as an additional safeguard.

2. Start the local briefing

From the royale-lab folder, run:

python3 gemini_setup.py
python3 serve.py --enable-gemini

The first command hides the key while you enter it. Open http://127.0.0.1:8501/ai.html, choose a topic and click Generate.

3. Use the result in Tableau

Successful briefings automatically save to tableau_support/gemini_insights.csv. Add it through Data → New Data Source → Text File.

In a new sheet, put Explanation on Text and Topic on Filters. Label the sheet “Gemini-generated explanation” and keep its evidence IDs and scope visible.

This page's hosted copy can display exported briefings. Generating a new response uses the local Python server. No API key is embedded in Tableau or the web page.
